Factoid Atlas — clinical color-coding scheme

Four toggleable color modes for the per-factoid embedding atlas. Each factoid (one dot) gets one label per dimension from GPT-OSS-120B. “none” is rendered in neutral grey so off-topic factoids recede. Colors are tuned for the near-black atlas background. This page is a static preview of taxonomy.py — react and I'll tweak hues/labels before any classification runs.

Drug-class buckets are grown from the team's bc_drugs_reference.csv + the drug_class field already on FDA factoids. Biomarker / setting / evidence axes are designed for breast oncology. Each dimension ≤ 13 labels → fits one byte in attrs.bin, alongside source & year.
